# Learn-Ds

Personal collection of Jupyter notebooks for learning data science and Python fundamentals.

## Contents

- **alma_mater.ipynb** — Data cleaning and exploratory analysis with `pandas` and `matplotlib`: normalizing messy text fields, mapping/grouping categorical data, cross-tabulations, binning, and basic visualizations.
- **strings.ipynb** — Basic Python string manipulation exercises (stripping whitespace, replacing characters, etc.).

## Requirements

- Python 3
- Jupyter (Notebook or JupyterLab)
- pandas
- matplotlib

Install dependencies with:

```bash
pip install pandas matplotlib jupyter
```

## Usage

Launch Jupyter and open any notebook:

```bash
jupyter notebook
```
